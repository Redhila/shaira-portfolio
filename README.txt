Shaira Afra Redhila Portfolio - GitHub Pages

IMPORTANT: Extract this ZIP on your computer first. Do not upload the ZIP file itself as the website.

Upload the contents of this folder to the ROOT of your GitHub repository, keeping index.html and the assets folder side by side. The assets folder contains the portfolio images and linked PDFs.

To publish: open the repository Settings > Pages > Build and deployment, choose Deploy from a branch, select main and /(root), then save.

Images have been optimized as WebP to reduce upload size while preserving their framing. The certificate images are not placed on additional white cards or backgrounds.
